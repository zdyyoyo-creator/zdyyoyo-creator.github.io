这个文件夹就是你的「文件区」。
==================================================

【怎么用】
1. 把你的文件直接拖进这个文件夹（PDF、Word、图片、zip、mp3 都行）。
2. 打开同目录下的 files.js，在方括号里照着示例加一段：
      { name: "网页上显示的名字", file: "files/你的文件名.pdf", desc: "一句话说明", tag: "PDF" }
3. 保存，然后刷新网站首页。

【能放多大】
· 单个文件建议 50MB 以内（GitHub 超过 50MB 会警告，超过 100MB 直接拒绝）
· 整个仓库建议 1GB 以内

【不想在网页上列出来？】
那就直接把文件丢进这个文件夹，在网页里用相对链接引用即可，
例如 <a href="files/你的文件.pdf">下载</a>，
只是「我的文件」区块里不会自动出现卡片（卡片来自 files.js 的清单）。

【文件名注意】
· 尽量别用空格，用 - 或 _ 代替，例如 my-resume-2025.pdf
· 中文文件名可以使用，但在某些旧浏览器里下载后名字可能变成乱码，
  求稳就用英文

【想删掉示例】
直接删掉 example.txt，并把 files.js 里那条示例记录删掉即可。
